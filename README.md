# Elevate-Labs-Internship-5
# Titanic Dataset - Exploratory Data Analysis

## Project Description
This repository contains the exploratory data analysis (EDA) of the Titanic dataset performed as Task 5 for the Data Analyst Internship.

## Files
1. `EDA_Titanic.ipynb`: Jupyter Notebook with complete analysis code
2. `Findings_Report.pdf`: Summary of key findings
3. `titanic.csv`: Dataset used for analysis

## Analysis Steps
1. Data loading and initial inspection
2. Data cleaning (handling missing values)
3. Univariate analysis (distributions)
4. Bivariate analysis (relationships between two variables)
5. Multivariate analysis (complex relationships)
6. Insights summarization

## Key Findings
- Survival rate was strongly correlated with passenger class and gender
- Higher fare passengers had better survival chances
- Children had higher survival rates than adults

## Requirements
- Python 3.x
- Jupyter Notebook
- Libraries: pandas, numpy, matplotlib, seaborn
